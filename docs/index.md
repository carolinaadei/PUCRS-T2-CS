**Documentação de especificação do ViajaJunto, desenvolvida para a disciplina de Construção de Software.**

## Sobre a documentação

Este site reúne os artefatos de especificação do projeto ViajaJunto — uma aplicação web de planejamento colaborativo de viagens. Aqui estão documentados a visão geral do produto, os requisitos funcionais e não funcionais, a arquitetura de software, o modelo de dados e a identidade visual da plataforma.

## Sobre o projeto

Planejar uma viagem em grupo é uma tarefa fragmentada e frustrante. As informações ficam espalhadas entre conversas de WhatsApp, planilhas improvisadas, e-mails e anotações individuais, sem nenhum lugar central onde todos os envolvidos possam ver o roteiro completo, as atividades planejadas e o quanto já foi gasto. Essa desorganização gera retrabalho, conflitos de agenda e perda de informações importantes, especialmente quando mais de uma pessoa está envolvida no planejamento.

O **ViajaJunto** propõe o desenvolvimento de uma aplicação web de planejamento colaborativo de viagens, onde um grupo de usuários pode, em conjunto, organizar roteiros com múltiplos destinos, datas, atividades e orçamentos em um único ambiente. A plataforma também oferece um mapa interativo com a visualização dos destinos e um sistema de avaliações da comunidade, permitindo que os usuários descubram e escolham destinos com base na experiência de outros viajantes.
